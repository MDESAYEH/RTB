# Club logo sources

Ten clubs have real local logos: Al Ittihad owner SVG preserved, eight FIBA competition-team images, Red Flames from a March 2024 Freetown match report. The Red Flames source is dated; current-version confirmation still requires the club. Full source URLs and identities are in manifest.json. No licence ownership is asserted; source attribution is retained. No historical claims were changed and no database writes were made. The existing public Badge now resolves central assets, preserving admin-supplied logos.
